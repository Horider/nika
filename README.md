# Пока идёт запись — Ника

2D-история от первого лица на Godot 4.7.2. Доступны все десять игровых дней, решения с последствиями и финал.

## Играть

[Играть в браузере](https://horider.github.io/nika/).

## Продолжать разработку

Откройте `game/project.godot` в Godot 4.7.2 и нажмите F5. Основная сцена — `Main.tscn`.
Текст хранится в `game/data/text.json`, события и маршруты — в `game/data/story.json`.
Каждый кадр — редактируемая сцена в `game/scenes`; общие картинки и звуки — в `game/assets`.
Дни связаны памятью решений, доверием Ники и допуском работодателя. Схема сохранений 10 читает версии 1–9.
В обычном профиле главное меню содержит «Продолжить», «Новая игра», «Настройки».
«Настройки» → «Тестовый профиль» открывает выбор любого дня и сцены, с отдельными автоматическим и ручным сохранениями.
Между днями игра продолжается автоматически через трёхсекундную заставку.
В редакторе и debug-сборке «Загрузка» открывает дни 1–10 для отдельного переигрывания без изменения основного сохранения.

Изменения в ветке main автоматически собирают Web-версию и публикуют её на GitHub Pages.
В Settings → Pages должен быть выбран источник GitHub Actions. Ссылка остаётся прежней при обновлениях.
Изменяя формат сохранений, сохраняйте поддержку предыдущих версий и стабильность событий.

## Локальная Web-сборка

Установите официальные шаблоны Godot 4.7.2. Создайте папку `web` в корне репозитория.
Выполните: `godot --headless --path game --export-release Web ../web/index.html`.
Раздайте `web` обычным HTTP-сервером; запуск через file:// не поддерживается.

Сохранения находятся в браузере, на устройстве игрока. Очистка данных сайта удаляет их.
Версия для браузера использует упакованные Noto Sans/Serif и потоковый звук для пространственных эффектов.
Графика поз статическая; птицы анимированы, входы с книгой используют видео.
Озвучка диалогов не добавлена. Звуки финальной части и коэффициенты доверия остаются рабочими вариантами для авторской оценки.

Этот репозиторий содержит редактируемую игровую сборку. Архивы, личные заметки, локальные сохранения,
рабочие генераторы раскадровок и история исходных материалов в публикацию не включены.
Открытая публикация не задаёт отдельную открытую лицензию на сюжет и графику.
Лицензии сторонних шрифтов находятся в `game/assets/fonts/*-OFL.txt`.
